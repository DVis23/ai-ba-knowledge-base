# Рефакторинг и техническая работа

**Цель:** изменить внутреннее устройство без изменения принятого поведения.

**Рефакторинг** улучшает структуру кода при сохранении внешнего результата.

**Техническая работа** обновляет зависимости, сборку, наблюдаемость или
эксплуатационные механизмы.

## Поток

1. Назвать сохраняемый контракт.
2. Определить область влияния по символам, зависимостям и графу.
3. Зафиксировать проверки поведения, которое может быть затронуто.
4. Выполнить изменение небольшими шагами.
5. После каждого шага запускать ближайшие проверки.
6. Для общего компонента проверить репрезентативных потребителей.

Если в ходе работы обнаруживается необходимость изменить продуктовый исход,
эта часть выделяется в SDD change.

Архитектурное решение записывается в ADR, если оно задаёт долговечное
ограничение для следующих изменений.
