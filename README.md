# AI-native разработка

База описывает инженерную среду, в которой ИИ-агенты работают через явные
источники, контракты, инструменты и проверки.

AI-native подход не равен генерации кода. Он решает пять задач:

1. сохраняет продуктовый смысл и происхождение решений;
2. фиксирует требуемое поведение;
3. отделяет повторяемую реализацию от уникальных правил;
4. получает проверяемые доказательства результата;
5. связывает артефакты для поиска и анализа влияния.

## Разделение полномочий

| Система | Владеет | Не владеет |
|---|---|---|
| BA-фреймворк | Источниками, решениями, правилами и происхождением знаний | Готовностью реализации |
| SDD / OpenSpec | Каноническим поведением и изменениями этого поведения | Платформенной реализацией |
| Декларативная платформа | Повторяемой технической механикой | Продуктовым смыслом |
| Тесты и evals | Доказательствами наблюдаемого результата | Формулировкой требования |
| Граф | Индексом связей, поиском, impact и trace gaps | Каноном и change workflow |
| Агентная среда | Исполнением процедур и доступом к инструментам | Методологией проекта |
