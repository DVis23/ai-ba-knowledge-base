# Интеграция ИИ в ИТ-проект: полный цикл

База собирает **фулл-стек ИИ-специалиста** — того, кто ведёт продукт по всему циклу с ИИ (включая Claude Code): **встреча с заказчиком → БА-документация → спеки и архитектура → код**. На каждой стадии — свой фреймворк, удерживающий стохастичную модель.

Читается с нуля: начни с [Концепции](01_Концепция/01_Зачем_ИИ_в_ИТ_проекте.md), даже если про LLM ничего не знаешь.
