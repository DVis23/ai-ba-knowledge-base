# Документация: AI + BA

Личная база по работе с Claude Code в роли BA. Два слоя: среда Claude Code и BA-надстройка поверх неё.

## С чего читать

1. **Если разбираешься в Claude Code** → сразу в `01_BA_надстройка/Триада.md`, дальше Фреймворк → Скиллы → Граф.
2. **Если нужна конкретная механика Claude** → `00_Claude_Code/` по нужному файлу.
3. **Если встретил незнакомый термин** → `99_Глоссарий.md`.
