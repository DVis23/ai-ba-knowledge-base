# Декларативная платформа

**Статус:** концептуальный.

Декларативная платформа сокращает повторяемую техническую работу. Разработчик
описывает желаемую структуру, а общий механизм создаёт или исполняет стандартное
поведение.

**Декларация** описывает, что существует и какие свойства оно имеет. Она не
перечисляет все шаги выполнения.

**Императивный код** задаёт последовательность действий. Он нужен там, где
поведение уникально или не выражается общей моделью.

Семейство содержит три самостоятельные модели:

1. [шаблонизатор приложений](01_Шаблонизатор_приложений.md) создаёт артефакты до
   запуска;
2. [платформенный runtime](02_Платформенный_runtime.md) исполняет общие правила
   во время работы;
3. [шаблонизатор с runtime](03_Шаблонизатор_с_runtime.md) объединяет обе модели
   через общий контракт.

| Модель | Основной момент работы | Результат |
|---|---|---|
| Шаблонизатор | Подготовка проекта | Файлы, схемы, миграции, SDK |
| Runtime | Работа приложения | Исполняемые операции и политики |
| Связка | Оба момента | Статический каркас и общее поведение |

Эти модели не являются стадиями зрелости. Каждая может использоваться отдельно.
Выбор описан в [границах применения](04_Границы_применения.md).
