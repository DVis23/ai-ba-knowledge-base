# Декларативная платформа

**Статус:** концептуальный.

В прикладных системах значительная часть кода повторяет уже известную механику:
поля данных превращаются в таблицы и API, права проверяются одинаково, формы
собираются из тех же описаний, а фоновые операции требуют одних и тех же
повторов и журналов. Декларативный подход выносит эту повторяемость в общую
модель. Проект описывает различия, а платформа воспроизводит стандартную часть.

У подхода есть два независимых механизма. [Шаблонизатор](01_Шаблонизатор_приложений.md)
работает до запуска приложения и создаёт файлы. [Runtime](02_Платформенный_runtime.md)
работает внутри приложения и исполняет общие правила для реальных запросов.
Проект может использовать любой из них отдельно.

Когда оба механизма читают одну декларацию, возникает
[связанная система](03_Шаблонизатор_с_runtime.md): из описания ресурса заранее
создаются типы и адаптеры, а во время работы runtime применяет права, аудит и
другие политики. Такая система уменьшает дублирование, но требует строгого
разделения платформенной механики и продуктовых правил.

[Границы применения](04_Границы_применения.md) помогают решить, когда достаточно
обычного кода, когда полезна генерация и когда оправдан общий runtime.
