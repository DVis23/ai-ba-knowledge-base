# Графы graph-ba

`graph-ba` несколько раз менял не только функции, но и назначение. Один и тот
же движок успел побыть индексом БА-документации, сквозным графом доказательств,
рабочей поверхностью изменений и владельцем SDLC.

Типы графов отличаются между собой хотя бы одним из трёх контрактов:

1. что считается источником истины, какие факты входят в граф и какие выводы
   из них допустимы;
2. кто владеет жизненным циклом изменения;
3. может ли состояние графа разрешать или запрещать поставку.
