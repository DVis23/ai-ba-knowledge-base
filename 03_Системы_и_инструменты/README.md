# Системы и инструменты

Методология задаёт способ рассуждения. Система воплощает часть методологии в
артефактах, командах и проверках.

- [BA-фреймворк](01_BA-фреймворк/) структурирует человеческие источники,
  решения и бизнес-знание.
- [OpenSpec](02_OpenSpec/) реализует change-oriented SDD.
- [Декларативная платформа](03_Декларативная_платформа/) сокращает повторяемую
  техническую реализацию.
- [Графы](04_Графы/) показывают разные назначения графовой модели.
- [Концептуальные альтернативы](05_Концептуальные_альтернативы.md) сохраняют
  полезные идеи других подходов без объявления их обязательными.
