# Референсная таксономия BA-артефактов

**Статус:** справочный.

Таксономия разделяет разные виды знания, чтобы правило не растворялось в
протоколе встречи, а предположение не выглядело как решение.

| Тип | Смысл |
|---|---|
| `SRC` | Первичный или производный источник |
| `TERM` | Термин предметной области |
| `FACT` | Подтверждённый факт |
| `DEC` | Решение уполномоченного человека |
| `RULE` | Бизнес-правило или вычисление |
| `OQ` | Открытый вопрос |
| `ASM` | Неподтверждённое предположение |

**Стабильный идентификатор** — имя, которое сохраняется при перемещении или
переименовании файла. По нему можно ссылаться на смысл из спецификации, кода и
графа.

**Типизированная связь** называет смысл отношения. Например,
`derived-from` означает происхождение, а `resolves` — закрытие вопроса решением.

Минимальные связи:

```text
FACT ──derived-from──> SRC
DEC  ──based-on──────> SRC
RULE ──approved-by───> DEC
DEC  ──resolves──────> OQ
ASM  ──derived-from──> SRC
```

Идентификатор помогает найти артефакт, но не делает его истинным. Авторитет
задаётся типом источника и человеческим подтверждением.

## Когда таксономия избыточна

Для небольшого проекта достаточно списка решений, правил и открытых вопросов
со ссылками на источники. Новые типы вводятся только тогда, когда смешение двух
видов знания уже приводит к ошибкам.
