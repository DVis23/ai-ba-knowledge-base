# Агентная среда

Агентная среда, или harness, превращает языковую модель из текстового
собеседника в исполнителя, который может исследовать проект, изменять его и
проверять результат.

Раздел описывает переносимую архитектуру, а не команды одного продукта.

  цикл исполнения.
- [Создание собственной среды](02_Создание_собственной_среды.md) — путь от API

- [Оркестрация и долгая работа](05_Оркестрация_и_долгая_работа.md) — подагенты,

## Четыре уровня

| Уровень | Роль |
|---|---|
| Модель | Рассуждает над переданным контекстом и выбирает следующий ответ или tool call |
| Провайдер | Предоставляет endpoint, аутентификацию и лимиты модели |
| Harness | Управляет циклом, инструментами, состоянием и permissions |
| Проектный слой | Задаёт инструкции, skills, проверки и владельцев артефактов |

Замена модели не должна менять проектный канон. Замена harness не должна
требовать переписывать спецификации, код и тесты.
