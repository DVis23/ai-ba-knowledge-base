# Контекст и кэш

Окно конечно, кэш с TTL. Оба определяют экономику и латентность сессии.

## Контекстное окно

- **Размер** — для Opus 4.7 (1M-вариант): до 1 000 000 токенов. Обычный Opus 4.7 — 200К.
- **Что попадает**: системный промпт, CLAUDE.md (все уровни), история сообщений, tool-результаты, прочитанные файлы, индекс memory.
- **Цена переполнения**: автоматическая компакция — теряются детали, остаётся summary. Дешевле не допускать.

## Компакция

- **Срабатывает** автоматически при приближении к лимиту.
- **Выбрасывается**: ранние сообщения и tool-результаты — уходят в summary.
- **Сохраняется**: системный промпт, CLAUDE.md, последние сообщения, текущий план/таски.
- **Явная компакция** — командой `/compact`. Полезна, когда понимаешь, что предыдущие шаги больше не нужны для оставшейся работы.

## Prompt cache

Anthropic кэширует стабильный префикс промпта. **TTL — 5 минут**: если в течение 5 минут идёт новый запрос с тем же префиксом, читается из кэша (быстрее и дешевле).

- **В кэше**: системный промпт, CLAUDE.md, ранние неизменённые сообщения.
- **Ломает кэш**: любое изменение раннего контекста (правка CLAUDE.md, удаление сообщения, инъекция системного контента).
- **Не ломает кэш**: добавление новых сообщений в конец.

## Практика выбора задержек (для `/loop`, `ScheduleWakeup`)

- **< 5 мин (60–270с)** — кэш тёплый. Подходит для активного опроса внешнего состояния (CI, deploy).
- **5 мин – 1 час (300–3600с)** — платим cache miss; ок если ждём долгое событие.
- **Не выбирай 300с** — худшее из обоих: платим miss без амортизации. Либо 270, либо 1200+.
- **Дефолт idle-tick** без конкретного сигнала — 1200–1800с (20–30 мин).
- **Не поллируй то, что харнес сам уведомит** (background-таски) — пустая трата кэша.

## Принципы экономии

|Принцип|Что значит|Что ломается без него|
|---|---|---|
|**Не клади всё в CLAUDE.md**|Каждая строка занимает окно постоянно|Cache miss при первом изменении дороже самого контента|
|**Длинные tool-результаты — в агента**|2000+ строк tool-вывода → делегируй Explore|Компакция съедает середину сессии|
|**Узкий формат ответа сразу**|«файл:строка», «да/нет + 1 строка»|Получишь простыню, разбухнет окно|
|**Не растягивай сессию искусственно**|Несвязанные задачи — новые сессии|Кэш мимо, контекст шумный|
