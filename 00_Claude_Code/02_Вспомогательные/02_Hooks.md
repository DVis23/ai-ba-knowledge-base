# Hooks

Shell-команды, выполняемые харнесом в ответ на события сессии. Единственный способ заставить что-то срабатывать автоматически — memory и CLAUDE.md просят, но не делают.

## Зачем существует

1. **Автоматизация невозможна через основные механизмы.** Skill ждёт триггера в запросе, memory подгружается по релевантности, CLAUDE.md статичен. «Само сработало при X» — только hook.
2. **Жёсткий контроль над опасным.** PreToolUse блокирует команду до выполнения: запрет `rm -rf`, обязательный линт перед коммитом, подтверждение деструктивного.
3. **Внешняя интеграция.** Уведомление в Slack при Stop, audit-журнал действий, статус в трекере.

## События

|Событие|Когда срабатывает|Что можно|
|---|---|---|
|**PreToolUse**|Перед каждым вызовом tool|Заблокировать, модифицировать вход, залогировать|
|**PostToolUse**|После каждого вызова tool|Среагировать на результат (формат, тест, push)|
|**UserPromptSubmit**|Пользователь отправил сообщение|Перехват, инъекция контекста, цензура|
|**Stop**|Claude закончил ход|Уведомление, финальный чек|
|**Notification**|Системное уведомление|Перенаправить в Slack/email|
|**SessionStart**|Сессия начинается|Загрузить динамический контекст|

Hook возвращает exit-code 0 (продолжаем) или non-zero (блокировка с сообщением в stderr).

## Конфигурация

`settings.json` — приоритет: local > project > user.

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          { "type": "command", "command": "scripts/check-bash.sh" }
        ]
      }
    ]
  }
}
```

- **matcher** — имя tool (`Bash`, `Edit`, `Write`) или regex.
- **command** — shell-команда, на вход JSON с контекстом события.
- **scope** — `~/.claude/settings.json` (user), `.claude/settings.json` (project, в git), `.claude/settings.local.json` (local, gitignored).

## Типичные сценарии

|Сценарий|Событие / matcher|Что делает|
|---|---|---|
|Автоформат после правки|PostToolUse / Edit, Write|Запускает prettier/black/gofmt по изменённому файлу|
|Блок опасных команд|PreToolUse / Bash|Грэп на `rm -rf /`, `git push --force` — exit 1 с сообщением|
|Тесты перед коммитом|PreToolUse / Bash matcher `git commit`|Запускает pytest/jest; провал → exit 1|
|Уведомление в Slack|Stop|`curl` в webhook с кратким summary|
|Загрузка ENV|SessionStart|Подгружает актуальные `.env` для сессии|

## Принципы дизайна

|Принцип|Что значит|Что ломается без него|
|---|---|---|
|**Быстро или асинхронно**|PreToolUse работает синхронно. > 500мс — асинхронь или вынеси в PostToolUse|Каждое действие в сессии тормозит|
|**Информативный exit**|При блокировке — внятное сообщение в stderr, что и почему|Claude не понимает причину, пытается обойти|
|**Идемпотентность**|Повторный запуск не ломает состояние|PostToolUse выполнится много раз — баги накапливаются|
|**Локально проверяемо**|Hook можно запустить вне Claude вручную|Отладка через сессию — пытка|
|**Shared, не local**|Командная логика в `.claude/settings.json`, не `.local`|У коллег поведение отличается|
