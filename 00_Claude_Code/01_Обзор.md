# Обзор: инструменты Claude Code

Claude Code — не один механизм, а несколько. Каждый из которых отвечает за свою задачу. Перепутаешь — поведение либо не сработает, либо вызовется не вовремя.

## Четыре основных механизма

||Когда грузится|Для чего|Пример из UpSushi|
|---|---|---|---|
|**CLAUDE.md**|Всегда|Конвенции проекта|«Документация на русском»|
|**Memory**|По релевантности|Факты о пользователе/проекте|«BA на UpSushi»|
|**Skill**|По триггеру или явному вызову|Процедура «как мы делаем X»|`/ba-refine-meeting`|
|**Agent**|Когда делегируешь подзадачу|Исследование с инструментами|Explore-агент|

Если механизм выбран неверно — переноси, не дублируй. Одна и та же информация в CLAUDE.md и memory = два источника правды и расхождение через неделю.

## Две группы

- **[01_Основные/](01_Основные/)** — четыре механизма выше. CLAUDE.md, Memory, Skills, Agents.
- **[02_Вспомогательные/](02_Вспомогательные/)** — обвязка: Hooks (автоматизация по событиям), MCP (внешние tools), Slash-commands (built-in vs skill), Plan mode (режим сессии), Контекст и кэш (экономика окна).

Каждая подпапка имеет свой `01_Обзор.md` — там границы между файлами внутри группы.
