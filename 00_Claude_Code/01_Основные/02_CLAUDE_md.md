# CLAUDE.md (файл конвенций)

Markdown-файл, который грузится в каждую сессию автоматически. Цена — занимает окно постоянно. Польза — устраняет повторное объяснение базовых правил проекта.

## Зачем существует

1. **Один источник для инвариантов.** «Документация на русском», «не коммить без ревью», «БД в RU-1» — повторять в каждом промпте дорого.
2. **Без CLAUDE.md правила живут в голове.** LLM не знает их, пользователь забывает повторить, результат — стохастика.
3. **Это контракт с LLM.** Что написано — считается известным. Что не написано — модель додумает.

## Что класть

- **Язык, тон, стиль документации и кода.** Пример — корневой [CLAUDE.md](../../../CLAUDE.md): жёсткие правила краткости.
- **Критичные «никогда не делай»** с точки зрения проекта: «не пересоздавай ID», «не используй ORM-генерацию миграций», «не коммить в main».
- **Указатели на ключевые документы**: README, глоссарий, конвенции. Контент — там, ссылка — здесь.
- **Терминология проекта**, без которой ответы будут неточными.

## Что НЕ класть

- **Процедуры** («как создать UC») → [Skills.md](04_Skills.md). Skill грузится по триггеру, CLAUDE.md — всегда.
- **Факты** («Иван — техлид», «дедлайн релиза 12 марта») → [Memory.md](03_Memory.md). Память подгружается по релевантности.
- **Длинные примеры и шаблоны** → отдельные документы, на которые CLAUDE.md ссылается.
- **Изменяющееся еженедельно** — дешевле хранить в memory и обновлять, чем PR-кать CLAUDE.md.

## Иерархия

|Файл|Scope|Когда переопределяет|
|---|---|---|
|`~/.claude/CLAUDE.md`|Все проекты пользователя|База — другие уровни наслаиваются сверху|
|`<project>/CLAUDE.md`|Корень проекта|Перекрывает user-уровень для этого проекта|
|`<project>/.claude/CLAUDE.md`|Локальные настройки (обычно gitignored)|Перекрывает project-уровень для конкретной машины|

Уровни конкатенируются, нижний — приоритетнее.

## Принципы дизайна

|Принцип|Что значит|Что ломается без него|
|---|---|---|
|**Минимум объёма**|Каждая строка стоит места в каждой сессии|Контекст набивается шумом, важное теряется|
|**Императивный тон**|«Не делай X», «Используй Y» — без хеджирования|LLM трактует как пожелание, нарушает выборочно|
|**Только инварианты**|То, что не меняется от задачи к задаче|Устаревает за неделю, верить нельзя|
|**Ссылки, не копии**|Указывай на источник, не дублируй|Расхождение с источником через первый merge|
|**Без воды**|Никаких «следует учитывать», «важно понимать»|Вода маскирует пустоту правила|

## Признак, что пора резать CLAUDE.md

- Файл больше 1 экрана — большая часть уже не работает как инвариант.
- Найдены три «может быть», «обычно», «как правило» — это не правила, это пожелания.
- Раздел не пересматривался полгода и не вспоминается — кандидат на удаление.
