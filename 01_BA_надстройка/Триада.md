# Триада: Framework + Skill + Graph

Три ноги одного стула. Каждая отдельно работает плохо, втроём — фундамент BA-работы с Claude.

## Роли

|Слой|Что даёт|Без него|
|---|---|---|
|**Фреймворк**|Схему: типы артефактов, допустимые рёбра, валидные ID|Skill изобретает структуру каждый раз|
|**Skill**|Процедуру наполнения схемы|Шаблоны мёртвые, фреймворк — стопка markdown-файлов|
|**Граф**|Хранилище результата + проверки целостности|Impact-анализ невозможен, расхождения между артефактами накапливаются|
