# Триада: Framework + Skill + Graph

Три ноги одного стула. Каждая отдельно работает плохо, втроём — фундамент структурированной работы с Claude.

## Роли

|Слой|Что даёт|Без него|
|---|---|---|
|**Фреймворк**|Схему: типы артефактов, допустимые рёбра, валидные ID|Skill изобретает структуру каждый раз|
|**Skill**|Процедуру наполнения схемы|Шаблоны мёртвые, фреймворк — стопка markdown-файлов|
|**Граф**|Хранилище результата + проверки целостности|Impact-анализ невозможен, расхождения между артефактами накапливаются|

## Где смыкаются

- Фреймворк → [Фреймворк.md](Фреймворк.md)
- Skill → [00_Claude_Code/01_Основные/04_Skills.md](../00_Claude_Code/01_Основные/04_Skills.md) (механика) + конкретные skills проекта
- Граф → [Граф.md](Граф.md)

## Конвейер на одном примере

Условный пайплайн: `вход → синтез → атомарные_единицы → группы → спецификации → реализация`.

|Шаг|Чем создаётся (skill)|Что проверяет граф|
|---|---|---|
|Вход → синтез|Читает источники, формирует сводку с типизированными ссылками|Все источники указаны, нет «вырвано из контекста»|
|Синтез → атом|Нарезает по шаблону Фреймворка, выдаёт ID каждой единице|ID уникальны, не пересекаются с существующими|
|Атом → группа|Объединяет связанные атомы по типизированному ребру|Нет сирот, нет циклов|
|Группа → спецификация|Генерит спеку по шаблону|Покрытие: все атомы попали хотя бы в одну спеку|
|Спецификация → реализация|Генерит код/артефакт|Каждая реализация трассируется до атома|

Каждый шаг — skill из [00_Claude_Code/01_Основные/04_Skills.md](../00_Claude_Code/01_Основные/04_Skills.md). Каждый артефакт — узел графа. Каждое стрелочное звено — типизированное ребро.

## Что ломается при выпадении одного

- **Убрать фреймворк** → skill каждый раз изобретает форму. Поля у похожих артефактов разные, граф не строится.
- **Убрать skill** → шаблоны мёртвые. Фреймворк описывает что должно получиться, но никто не знает как. Каждый артефакт собирается вручную.
- **Убрать граф** → impact-анализ невозможен. После правки атомарного артефакта неизвестно, какие группы и спеки протухли. На 600+ артефактах ручной ревью бесполезен.
