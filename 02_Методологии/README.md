# Методологии

Методологии отвечают на разные вопросы и могут использоваться вместе.

- [SDD](01_SDD.md) управляет намерением и изменением поведения.
- [TDD](02_TDD.md) помогает проектировать детерминированную реализацию через тест.
- [BDD и ATDD](03_BDD_и_ATDD.md) выражают поведение примерами.
- [DDD и ADR](04_DDD_и_ADR.md) удерживают доменную и архитектурную целостность.
- [Evals и непрерывная верификация](05_Evals_и_непрерывная_верификация.md)
  собирают доказательства для кода и AI-поведения.
