# Обзор: Основные механизмы


|Файл|Когда грузится|Цена|Для чего|
|---|---|---|---|
|**[CLAUDE_md.md](02_CLAUDE_md.md)**|Всегда|Занимает окно в каждой сессии|Конвенции, инварианты, «никогда не»|
|**[Memory.md](03_Memory.md)**|По релевантности|Подгружается только когда нужно|Факты о пользователе/проекте/внешних системах|
|**[Skills.md](04_Skills.md)**|По триггеру или явному `/<name>`|Грузится только при срабатывании|Процедура «как мы делаем X»|
|**[Agents.md](05_Agents.md)**|При делегировании подзадачи|Отдельный контекст-окно|Изоляция шумного исследования|

## Где провести границу

- Декларативное-универсальное (правила проекта) → **CLAUDE.md**.
- Декларативное-узкое (факты о людях, инициативах, внешних системах) → **Memory**.
- Процедурное (шаги, повторяемые на похожих входах) → **Skill**.
- Подзадача с собственным контекстом → **Agent**.

Дубликат недопустим: одну и ту же информацию в двух механизмах — расхождение неизбежно.
