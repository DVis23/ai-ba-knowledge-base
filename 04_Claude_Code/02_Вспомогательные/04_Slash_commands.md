# Slash-commands

`/<name>` в чате. Два разных явления под одним синтаксисом — встроенные команды клиента и skills проекта.

## Два типа

|Тип|Источник|Что делает|
|---|---|---|
|**Built-in**|CLI (`/help`, `/clear`, `/config`, `/model`, `/compact`)|Управление сессией, конфигом, харнесом|
|**Skill**|Файл в `.claude/skills/` или плагин|Триггерит процедуру, описанную в файле|

Разрешение конфликта: встроенные имеют приоритет. Skill с именем `/help` не сработает.

## Граница

- Меняет **состояние клиента/сессии** (очистить контекст, переключить модель, перезапустить) → built-in.
- Выполняет **процедуру в проекте** → skill. См. [Skills.md](../01_Основные/04_Skills.md).

## Принципы именования (для skills)

|Принцип|Пример|Что ломается без него|
|---|---|---|
|**Префикс по домену**|`/ba-*`, `/eng-*`, `/qa-*`|Конфликты при росте; неясно, в какой роли вызывается|
|**Глагол в названии**|`/docs-refine-meeting`, не `/docs-meeting`|Skill без глагола читается как сущность, LLM не знает что делать|
|**Стабильность имени**|`/docs-refine-meeting` не переименовывается каждый месяц|Ломаются ссылки в других skills и в memory|
|**Уникальная семантика**|`/docs-create-spec` ≠ `/docs-new-spec`|Один skill на одну процедуру — иначе оба размываются|

## Built-in: что доступно в Claude Code

Реальные built-in (управление сессией):

- `/help` — справка
- `/clear` — очистить контекст текущей сессии
- `/compact` — явная компакция
- `/config` — открыть настройки
- `/model` — переключить модель
- `/fast` — fast-режим (Opus с ускоренным выводом)

Skills из стандартных плагинов, **которые легко перепутать с built-in**:

- `/init` — инициализация CLAUDE.md в проекте
- `/loop` — запустить итерации на интервале (см. [06_Контекст_и_кэш.md](06_Контекст_и_кэш.md) про выбор интервала)
- `/schedule` — создать cron-задачу для удалённого агента
- `/review`, `/security-review` — ревью PR / security-аудит
- `/verify`, `/run` — проверка изменений и запуск приложения

Граница простая: built-in работает «голым» Claude Code без плагинов; skill требует установленного плагина или файла в `.claude/skills/`. Актуальный список — через `/help`.

## Связь с другими механизмами

- Built-in — управление клиентом, не покрывается остальной документацией.
- Skill — см. [Skills.md](../01_Основные/04_Skills.md).
- Hook ≠ slash: hook срабатывает на событие, slash — на явный ввод. См. [Hooks.md](02_Hooks.md).
