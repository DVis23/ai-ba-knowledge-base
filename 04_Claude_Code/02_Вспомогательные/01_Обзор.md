Обвязка вокруг основных. Расширяют арсенал, автоматизируют, управляют сессией. Без них Claude работает — но узко.

|**[MCP.md](03_MCP.md)**|Новые tools от внешних серверов|Нужен доступ к внешней системе (Figma, Linear, БД) с типизированным интерфейсом|

|**[Plan_mode.md](05_Plan_mode.md)**|Режим проектирования без действий|Задача затрагивает несколько файлов или незнакомую область|
|**[Контекст_и_кэш.md](06_Контекст_и_кэш.md)**|Экономика окна и prompt cache (TTL 5 мин)|Длинные сессии, /loop, выбор задержек|

## Где провести границу

- Нужна **автоматика на событие** (не на запрос) → Hook.
- Нужен **новый tool** в арсенал Claude → MCP-сервер.
- Команда **меняет состояние клиента** (`/clear`, `/config`) → built-in slash. Команда **запускает процедуру в проекте** → skill ([01_Основные/04_Skills.md](../01_Основные/04_Skills.md)).
- Решение неочевидно или цена ошибки высока → Plan mode.
- Длинная сессия / повторяющиеся опросы → пересмотри задержки в Контекст_и_кэш.
