# Графы graph-ba

`graph-ba` несколько раз менял не только функции, но и назначение. Один и тот
же движок успел побыть индексом БА-документации, сквозным графом доказательств,
рабочей поверхностью изменений и владельцем SDLC. Позднее проект UpSushi
вернул ему роль производной трассировочной проекции.

Раздел разделяет эти модели. «Другой граф» здесь означает смену хотя бы одного
из трёх контрактов:

1. что считается источником истины;
2. кто владеет жизненным циклом изменения;
3. может ли состояние графа разрешать или запрещать поставку.
